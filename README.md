# Sparvereinsverwaltung

Windows-Programm für österreichische Sparvereine: Mitglieder, Einzahlungen, Strafen,
Zinsen mit KESt, Jahresauszahlung und Vereinsabrechnung – mit Ausdrucken für jeden Schritt.

Alle Daten bleiben **auf Ihrem Rechner**. Das Programm braucht kein Konto und keine Cloud;
Internet nur, wenn Sie auf der Startseite selbst nach Updates suchen.

## Download

👉 **[Neueste Version herunterladen](https://github.com/aortner/Sparvereinsverwaltung/releases/latest)**
(Datei `Sparvereinsverwaltung-<Version>.zip` unter „Assets“)

1. ZIP entpacken und den Ordner z. B. nach `C:\Sparverein` kopieren (nicht nach „Programme“).
2. `Sparverein.exe` starten.
3. Meldet Windows *„Der Computer wurde durch Windows geschützt“*: **Weitere Informationen** →
   **Trotzdem ausführen**.

Voraussetzung: Windows 10 (ab Version 2004) oder Windows 11. Sonst muss nichts installiert werden.

## Update

Ab Version 1.0.1: Auf der **Startseite** auf **„Nach Updates suchen“** klicken. Gibt es eine neue
Version, installiert **„Jetzt aktualisieren“** sie – die Datenbank wird vorher gesichert, die
Vereinsdaten bleiben erhalten. Bei Version 1.0.0 einmalig die neue ZIP herunterladen und die
Programmdateien ersetzen (`sparverein.db` behalten).

## Funktionen

- Mitgliederverwaltung mit CSV-Import, Mitgliederliste und runden Geburtstagen
- Einzahlungen pro Termin erfassen, auch per CSV, mit Kontrolle vor dem Speichern
- Strafen bei Pflichtterminen, Essensabzug, Rundung
- Zinsen taggenau bis zum Auszahlungstag, KESt-Abzug
- Auszahlungsliste mit Identitätsprüfung, Einzelabrechnungen zum Ausdrucken
- Rangliste und Jahresabrechnung des Vereins
- Export der Mitglieder und Einzahlungen

## Wichtig

Führen Sie alle Einzahlungen, Auszahlungen und Mitgliederlisten zusätzlich **schriftlich** und
sichern Sie die Datei `sparverein.db` regelmäßig. Vor jeder Auszahlung **„Auszahlung neu
berechnen“** ausführen und die Ergebnisse prüfen. Es gelten die
[Nutzungsbedingungen](Nutzungsbedingungen.md).
